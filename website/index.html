FAQ

Aksar poochhe jaane wale sawal.

Kya ye offline kaam karta hai?

Haan. Transcription local Whisper se hota hai, to internet ke bina bhi chalta hai. Cloud providers optional hain.

Mera data kahan rehta hai?

Meeting history aur settings aapke computer par local database me rehti hain. API keys encrypted store hoti hain.

Kaun si meetings me kaam karta hai?

Zoom, Google Meet, Teams ya koi bhi app, kyunki ye system audio capture karta hai.

Kin platforms par milta hai?

Windows aur Ubuntu/Linux ke liye download available hai. macOS jald aayega.
